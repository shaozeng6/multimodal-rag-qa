# 演示文档（虚构内容）

本目录提供一套**虚构的演示文档**，用于多模态 RAG 系统的功能演示、截图与公开分享。
品牌、型号、电话号码、邮箱、地址等均为杜撰，不存在版权与隐私风险，可放心用于 README 配图或线上演示。

| 文件 | 内容 | 说明 |
|---|---|---|
| `云杉SS-350使用说明书.pdf` | 智能手冲咖啡机说明书（8 页） | 含结构示意图、流程图、参数对比图、规格表、故障表、错误代码表 |
| `云杉智能售后服务手册.pdf` | 售后服务手册（4 页） | 含服务渠道响应时长图、保修政策表、退换货政策、FAQ |

## 内容设计（对齐多模态 RAG 能力）

- **图文结合**：产品结构示意图（图 1）带编号部件，图片描述由入库管线的多模态模型自动生成，可用「部件在哪个位置」类问题演示以图找文。
- **表格与图表数据一致**：冲煮模式的水温 / 时长（88℃ / 12 分钟等）在正文表格与图 3 柱状图中保持一致，可演示「看图问答」与图文一致性校验。
- **跨文档同一事实**：主机 24 个月保修、除垢频率（每 3 个月 / 累计 120 次）、错误码 E03 等在两份文档中重复出现，适合演示跨文档检索与引用证据。
- **可直接截图的安全界面**：本目录之外，系统的入库进度、系统设置、知识库管理页截图本身不含文档原文，也可安全用于演示。

## 演示提问建议

> 使用前先在「知识库管理」上传以上两个 PDF，等入库完成后提问。

- 文本检索：「SS-350 的水箱容量是多少？」（查规格表）
- 表格问答：「冰萃模式的粉水比是多少？」（查模式表）
- 多模态（以文找图）：「说明书里标注的 3 号部件是什么？」（图片描述 + 文本桥接）
- 多模态（以图搜文）：「把结构示意图上传，问这个部件怎么清洁」（图 1 → 清洁与保养章节）
- 图表问答：「图 3 中哪个模式冲煮时间最长？」（柱状图理解）
- 跨文档：「主机保修期多久？」（两份文档都含此信息，看引用证据来源）
- 错误码：「显示 E02 是什么问题？」（查错误代码表）
- 售后场景：「除垢剂要用多少克？」（FAQ 与保养章节交叉检索）

## 重新生成

所有产物都由 `source/` 下的脚本与模板生成：

1. 配图：`python source/gen_images.py`（需 matplotlib，Windows 下自动使用微软雅黑）
2. PDF：用 Chrome 将对应 HTML 打印为 PDF：

   ```bash
   chrome --headless --disable-gpu --no-pdf-header-footer \
     --print-to-pdf="云杉SS-350使用说明书.pdf" \
     "file:///绝对路径/source/yunsan_ss350_manual.html"
   ```

> 提示：系统上传接口仅接受 PDF，请勿直接上传 `source/images/*.png`。
